# ASBA AI — منصة تدوين عربية متكاملة

مدونة شخصية احترافية باسم **ASBA AI**: واجهة عامة أنيقة للزوار، ولوحة تحكم آمنة ومحمية لإدارة المقالات والصور والإعلانات والإعدادات — مبنية بـ **Next.js 15 + TypeScript + Tailwind CSS**، جاهزة للنشر على **Vercel** مع قاعدة بيانات **Postgres** مجانية.

---

## المزايا

### واجهة الزوار (RTL عربي كامل)
- صفحة رئيسية: قسم ترحيبي، المقالات المميزة، أحدث المقالات، الأقسام، نبذة عن صاحب المدونة.
- صفحة مقال احترافية: غلاف، كاتب، تاريخ، وقت قراءة، مشاهدات، أزرار مشاركة، مقالات ذات صلة، شريط تقدم قراءة.
- تصفح حسب القسم، أرشيف كامل مع ترقيم صفحات، بحث في العناوين والمحتوى.
- **الوضع الداكن / الفاتح** مع حفظ الاختيار، تصميم متجاوب كامل (هاتف/تابلت/كمبيوتر).
- صفحات ثابتة: من نحن، اتصل بنا (نموذج يصل للوحة التحكم)، سياسة الخصوصية، شروط الاستخدام، إخلاء المسؤولية، أعمالي ومشاريعي.

### لوحة التحكم `/admin`
- تسجيل دخول آمن باسم مستخدم وكلمة مرور (لا يوجد تسجيل عام إطلاقًا).
- **محرر نصوص غني** (Quill): عناوين، قوائم، اقتباسات، روابط، فيديو مضمن، إدراج صور من المكتبة أو رابط، **تحكم بحجم أي صورة داخل المحتوى بالنقر عليها**.
- إدارة المقالات: مسودة / نشر فوري / **جدولة نشر مستقبلية** (تظهر تلقائيًا في موعدها دون cron)، مقتطف تلقائي، وسوم، تصنيف، مقال مميز.
- SEO لكل مقال: عنوان ووصف مخصصان + صورة OG مخصصة للمشاركة.
- مكتبة وسائط: رفع متعدد، **تصغير وضغط تلقائي في المتصفح** (حد أقصى 1600px) لتسريع الموقع، نسخ الرابط، حذف.
- نظام إعلانات: 7 مساحات (أعلى/أسفل الرئيسية، أعلى/وسط/أسفل المقال، الشريط الجانبي، أسفل الموقع) — تفعيل مستقل لكل مساحة ولصق أي كود (AdSense…).
- إدارة التصنيفات والصفحات الثابتة ورسائل الزوار.
- إعدادات: اسم المدونة، الشعار، الوصف، روابط التواصل، **اللون المميز (5 هويات لونية)**، نص التذييل.
- إحصائيات **حقيقية**: مشاهدات كل مقال، مخطط آخر 14 يومًا، المقالات الأكثر مشاهدة.

### SEO
- ميتا لكل صفحة، OpenGraph وTwitter Cards، `sitemap.xml`، `robots.txt`، `rss.xml`، بيانات منظمة JSON-LD للمقالات، روابط دلالية (Slugs) عربية أو لاتينية.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة والخادم | Next.js 15 (App Router) + React 19 + TypeScript |
| التنسيق | Tailwind CSS 3 + متغيرات CSS للهوية اللونية |
| قاعدة البيانات | Postgres في الإنتاج (Neon / Vercel Postgres) — SQLite للتطوير المحلي تلقائيًا |
| المحرر | Quill 2 |
| المصادقة | جلسة موقعة HMAC في كوكي HttpOnly + scrypt لكلمة المرور |
| الصور | تخزين في قاعدة البيانات وتقديم عبر `/api/media/[id]` مع تخزين مؤقت |

لا توجد خدمات خارجية مدفوعة ولا مفاتيح API إضافية — كل شيء داخل المشروع.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local
# عدّل ADMIN_USERNAME وADMIN_PASSWORD في .env.local ثم:
npm run dev
```

افتح `http://localhost:3000` ولوحة التحكم على `http://localhost:3000/admin`.

بدون `DATABASE_URL` يستخدم الموقع تلقائيًا قاعدة SQLite في مجلد `data/` (مناسبة للتجربة فقط).

## النشر على Vercel (خطوة بخطوة)

### 1) إنشاء قاعدة البيانات (مجاني)
- سجّل في [neon.tech](https://neon.tech) (أو استخدم Vercel Postgres / Supabase).
- أنشئ مشروعًا جديدًا وانسخ **Connection String** (يفضّل النسخة Pooled).

### 2) الاستيراد في Vercel
- [vercel.com/new](https://vercel.com/new) → اختر مستودع `asba` → Vercel يكتشف Next.js تلقائيًا.
- في خطوة **Environment Variables** أضف:

| المتغير | القيمة | ملاحظة |
|---|---|---|
| `DATABASE_URL` | رابط Postgres من الخطوة 1 | **مطلوب** |
| `ADMIN_USERNAME` | اسم المستخدم للدخول | **مطلوب** |
| `ADMIN_PASSWORD` | كلمة مرور قوية | **مطلوبة** — يمكنك تغييرها لاحقًا من اللوحة |
| `SESSION_SECRET` | نص عشوائي طويل | اختياري (يُولَّد تلقائيًا) |
| `NEXT_PUBLIC_SITE_URL` | `https://yourdomain.com` | اختياري — يضبط روابط SEO |

### 3) Deploy
- اضغط Deploy وبعد انتهاء النشر افتح `https://your-app.vercel.app/admin`.
- سجّل الدخول باسم المستخدم وكلمة المرور، ثم **غيّر كلمة المرور** من «كلمة المرور» في القائمة.
- كل المحتوى الأولي (الصفحات، التصنيفات، الإعدادات) جاهز ويُنشأ تلقائيًا مع أول زيارة.

### ربط نطاق خاص
Vercel → Project → Settings → Domains → أضف نطاقك واتبع تعليمات DNS.

## الأمان

- لا يوجد تسجيل حسابات من الواجهة العامة — حساب مدير واحد فقط.
- كل مسارات `/admin` و`/api/admin/*` تُتحقق من الجلسة **في الخادم** (Layout guard + كل Route Handler).
- كوكي الجلسة: `HttpOnly` + `SameSite=Lax` + `Secure` على HTTPS، وتنتهي بعد 7 أيام.
- كلمة المرور لا تُخزَّن نصًا أبدًا: scrypt مع ملح عشوائي.
- حد لمحاولات الدخول: 6 محاولات / 15 دقيقة لكل IP.
- إحصائيات مجهولة الهوية بالكامل (عدّاد فقط — لا عناوين IP ولا ملفات تتبع).
- نموذج التواصل محمي من السبام بحقل فخ مخفي.

> ⚠️ **مهم:** إذا شاركت توكن GitHub في أي مكان عام (كالمحادثات)، أنشئ توكنًا جديدًا واحذف القديم من GitHub → Settings → Developer settings.

## قاعدة البيانات — Neon (مربوطة فعليًا)

المشروع مربوط بمشروع Neon **asba** (`wispy-dew-85377643`) على الفرع **production** عبر ملف `neon.ts` من `@neon/config`:

```bash
# سحب متغيرات الاتصال إلى .env.local (DATABASE_URL + متغيرات الفرع)
neon env pull

# تطبيق سياسة الخدمات المعلنة في neon.ts (Postgres + Functions + Realtime)
neon deploy
```

- `DATABASE_URL` في `.env.local` هو رابط **pooled** من Neon — الأنسب لتطبيقات الويب وVercel (سائق `pg` كما توصي مهارة neon-postgres).
- يستخدم التطبيق `attachDatabasePool` من `@vercel/functions` لإعلام منصة Vercel عن اتصالات Pool النشطة.
- الدوال: `hello.ts` نُشرت على الفرع (`neon functions get hello`)، ويمكن تشغيلها محليًا بـ `neon dev` ثم استدعاؤها على `http://localhost:8787`.
- للتطوير على فرع معزول: `neon checkout dev --create` — كل فرع يحصل على قاعدة ونسخة دوال مستقلة.

**على Vercel:** نفس `DATABASE_URL` (pooled) + `ADMIN_USERNAME` + `ADMIN_PASSWORD` في Environment Variables — لا حاجة لأي متغير آخر.

## بنية المشروع

```
src/
├── app/
│   ├── (public)/          # واجهة الزوار: الرئيسية، المقالات، الأقسام، البحث، الصفحات

│   │   ├── login/         # صفحة الدخول
│   │   └── (panel)/       # لوحة التحكم (محمية): مقالات، وسائط، إعلانات، إعدادات…
│   ├── api/
│   │   ├── admin/         # مسارات الإدارة المحمية
│   │   ├── media/[id]/    # تقديم الصور
│   │   ├── stats/         # تسجيل المشاهدات
│   │   └── contact/       # نموذج التواصل
│   ├── sitemap.xml/ robots.txt/ rss.xml/
├── components/            # مكوّنات الواجهة العامة + لوحة التحكم
├── lib/                   # قاعدة البيانات، المصادقة، الاستعلامات، الإعدادات، البذر
```
